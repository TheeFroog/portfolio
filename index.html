Sobre mí

Soy una persona curiosa y con interés por la tecnología, especialmente por todo lo relacionado con la informática y el desarrollo web. Me gusta aprender de forma práctica y descubrir cómo funcionan las herramientas que utilizo en el día a día. Considero que la constancia y la capacidad de aprender de los errores son importantes para mejorar.

Qué sé hacer

Actualmente estoy comenzando a ampliar mis conocimientos sobre programación y creación de páginas web. Me interesa especialmente comprender bien los fundamentos antes de avanzar hacia contenidos más complejos. En este curso espero adquirir una buena base de desarrollo web y disfrutar del proceso de aprendizaje, incluso cuando algunas partes resulten difíciles.

Qué quiero aprender

  • Utilizar herramientas informáticas de forma autónoma.
  • Buscar información y recursos para resolver problemas
  • Trabajar con editores de código y organizar archivos
  • Crear documentos sencillos utilizando HTML
  • Aprender nuevas herramientas mediante la práctica
  • Organizar tareas y proyectos de forma estructurada

Qué quiero aprender

  1. Comprender correctamente la estructura y los elementos fundamentales de HTML.
  2. Aprender a crear páginas web bien estructuradas, accesibles y fáciles de mantener.
  3. Adquirir una base de CSS y JavaScript para poder desarrollar páginas más completas e interactivas.
